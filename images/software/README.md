# Software artwork mirror

This directory is maintained by `scripts/sync_software_logos.py`.

Canonical software logos remain in their source repositories. The website mirrors an existing logo unchanged from the first available conventional location:

- `man/figures/logo.svg`
- `man/figures/logo.png`
- `assets/images/logo.svg`
- `assets/images/logo.png`
- `logo.svg`
- `logo.png`

No substitute artwork is generated when a canonical logo is absent.
